How it works

Ingestion runs once, offline. This page only calls the retrieval endpoint.

  1. ExtractPyMuPDF reads text page by page, keeping page numbers
  2. Chunk500-character windows, 75 overlap, stride 425
  3. Embedall-MiniLM-L6-v2, 384-dim, run locally
  4. StoreChromaDB collection pdf_chunks, cosine space
  5. RetrieveQuery embedded with the same model, nearest chunks returned

Score = 1 − cosine distance (cosine similarity; higher is more similar). Scores are relative within this model and document. Chunks are fixed character windows, so they can start or end mid-word.
